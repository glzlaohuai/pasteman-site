자주 묻는 질문에 대한 답변입니다. 찾는 내용이 없다면 아래로 문의해 주세요.

PasteMan은 어떻게 여나요?

어떤 앱에서든 ⇧⌘V를 누르거나 메뉴 막대의 PasteMan 아이콘을 클릭하세요. 단축키는 ‘설정 › 일반’에서 변경할 수 있습니다.

PasteMan이 복사한 내용을 기록하지 않는 이유는 무엇인가요?

기록이 일시 정지되지 않았는지(메뉴 막대 아이콘 › 기록 일시 정지), 복사한 앱이 ‘설정 › 개인정보 보호 › 다음 앱에서 복사한 항목 무시’에 들어 있지 않은지 확인하세요. 암호 및 기타 기밀 콘텐츠는 절대 기록되지 않습니다. macOS에서 PasteMan이 클립보드를 읽어도 되는지 물으면 ‘항상 허용’을 선택하세요. 현재 설정은 ‘설정 › 개인정보 보호’에 표시됩니다.

PasteMan이 대신 붙여넣을 수 있나요?

네. ‘설정 › 일반 › 활성 앱에 자동으로 붙여넣기’를 켠 다음, ‘시스템 설정 › 개인정보 보호 및 보안 › 손쉬운 사용’에서 PasteMan을 추가하세요. 이 옵션을 켜지 않으면 선택한 항목이 클립보드에 복사되며, ⌘V를 눌러 붙여넣으면 됩니다.

여러 Mac 간에 어떻게 동기화하나요?

‘설정 › 동기화’에서 같은 Apple 계정으로 로그인한 각 Mac의 iCloud 동기화를 켜세요. 또는 로컬 네트워크 동기화를 켜고 두 Mac에 표시된 코드를 확인하여 페어링하세요.

모음과 스마트 모음은 무엇인가요?

모음에는 직접 추가한 항목이 담기며(패널에서 ⌘S), 기록을 얼마나 보존하든 관계없이 유지됩니다. 스마트 모음은 저장된 검색입니다. 패널에서 필터링한 다음 ⌘F 메뉴에서 ‘스마트 모음으로 저장’을 선택하세요.

스니펫 매크로는 어떻게 작동하나요?

모음에 보관된 텍스트에는 {날짜}, {클립보드}, {커서} 같은 매크로를 넣을 수 있습니다. 붙여넣을 때 PasteMan이 이를 채워 줍니다. ‘설정 › 모음’에서 매크로를 관리하고, 직접 매크로를 추가하고, 각 매크로가 삽입할 내용을 선택할 수 있습니다.

어떤 검색 단축 입력이 있나요?

검색 필드에 앱은 @, 콘텐츠 종류는 #(#이미지), 파일 확장자는 .(.pdf), 모음은 /를 입력하거나 ‘오늘’, ‘어제’ 같은 날짜 단어를 입력한 다음 Tab 또는 Return 키를 누르면 필터로 바뀝니다.

기록은 어떻게 삭제하나요?

패널에서 ⌘⌫로 항목을 하나씩 삭제하거나 ‘설정 › 개인정보 보호’에서 모두 지우세요. 동기화가 켜져 있으면 다른 기기의 기록도 함께 지워집니다.

도움이 더 필요하신가요?

GitHub에서 문제를 신고하거나 아이디어를 제안해 주세요. 사용 중인 macOS 버전과 당시 하던 작업을 함께 적어 주세요.
