# pasteman-site

The website of [PasteMan](https://pasteman.hiimobapps.cn), a clipboard history app for Mac, served by
GitHub Pages at pasteman.hiimobapps.cn.

These files are generated; the sources live with the app and are rebuilt with `site/build.py`.
Questions and bug reports about PasteMan are welcome as [issues](https://github.com/glzlaohuai/pasteman-site/issues).
