Assistance

Réponses aux questions fréquentes. Si la vôtre n’y figure pas, contactez-nous ci-dessous.

Comment ouvrir PasteMan ?

Appuyez sur ⇧⌘V dans n’importe quelle app, ou cliquez sur l’icône de PasteMan dans la barre des menus. Vous pouvez modifier le raccourci dans « Réglages › Général ».

Pourquoi PasteMan n’enregistre-t-il pas ce que je copie ?

Vérifiez que l’enregistrement n’est pas suspendu (icône de la barre des menus › Suspendre l’enregistrement) et que l’app d’où vous copiez ne figure pas dans « Réglages › Confidentialité › Ignorer les copies de ces apps ». Les mots de passe et autres contenus confidentiels ne sont jamais enregistrés. Si macOS vous demande si PasteMan peut lire le presse-papiers, choisissez « Toujours autoriser » ; le réglage actuel est indiqué dans « Réglages › Confidentialité ».

PasteMan peut-il coller à ma place ?

Oui. Activez « Réglages › Général › Coller automatiquement dans l’app active », puis ajoutez PasteMan dans « Réglages Système › Confidentialité et sécurité › Accessibilité ». Sans cela, l’élément choisi est placé dans le presse-papiers et vous appuyez sur ⌘V.

Comment synchroniser mes Mac ?

Dans « Réglages › Synchronisation », activez la synchronisation iCloud sur chaque Mac connecté au même compte Apple, ou activez la synchronisation sur le réseau local et jumelez les Mac en confirmant le code affiché sur les deux.

Comment voir l’historique de mon Mac sur iPhone ou iPad ?

Installez PasteMan sur votre iPhone ou votre iPad avec le même compte Apple et laissez-y la synchronisation iCloud activée (elle l’est par défaut). Sur le Mac, activez la synchronisation iCloud dans « Réglages › Synchronisation ». Sur un même réseau, vous pouvez aussi activer la synchronisation sur le réseau local sur les deux appareils ; elle fonctionne tant que PasteMan est ouvert sur l’iPhone ou l’iPad.

Que sont les collections et les collections intelligentes ?

Une collection contient les éléments que vous y placez (⌘S dans le panneau) ; ils sont conservés quelle que soit la quantité d’historique gardée. Une collection intelligente est une recherche enregistrée : filtrez le panneau, puis choisissez « Enregistrer comme collection intelligente » dans le menu ⌘F.

Que comprend PasteMan Pro ?

Les collections, les collections intelligentes, les macros d’extraits et, sur Mac, la modification avant de coller (⌘E). C’est un achat unique lié à votre compte Apple, commun à votre Mac, votre iPhone et votre iPad ; tout le reste de PasteMan est gratuit. Vous l’avez déjà acheté sur un autre appareil ? Ouvrez « Réglages › PasteMan Pro » et choisissez « Restaurer l’achat ».

Comment fonctionnent les macros d’extraits ?

Le texte conservé dans une collection peut contenir des macros comme {date}, {pressepapiers} ou {curseur}. Lorsque vous le collez, PasteMan les remplit. Gérez les macros, ajoutez les vôtres et choisissez ce que chacune insère dans « Réglages › Collections ».

Quels raccourcis de recherche sont disponibles ?

Dans le champ de recherche, tapez @ pour une app, # pour un type de contenu (#image), . pour une extension de fichier (.pdf), / pour une collection, ou un mot de date comme « aujourd’hui » ou « hier », puis appuyez sur Tab ou Retour pour le transformer en filtre.

Comment supprimer mon historique ?

Supprimez un élément avec ⌘⌫ dans le panneau, ou effacez tout dans « Réglages › Confidentialité ». Si la synchronisation est activée, l’historique de vos autres appareils est aussi effacé.
